How it works

already pay for.

01 · Plan

A markdown checklist

Projects, a repo, a test gate, a budget and - [ ] tasks. That's the whole interface. Relay writes results back in place.

02 · Capacity

Find the waste

Reads your Agent37 budget live, API spend from its own ledger, and Claude/ChatGPT plan windows. Keeps a reserve for your day and burns what's most likely to go to waste first.

An Agent37 platform cron wakes the instance at 23:00. Each task gets one agent and a test gate, then a commit on relay/night-<date> and a draft PR per project.

The engine

It can't get stuck
while you sleep.

Nobody is awake to babysit an overnight agent. Relay fails over the moment a model hits a limit, and climbs an unstick ladder when the agent loops, hangs or goes nowhere: a cheap second opinion, then a stronger model, then a clean reset. It drops back to the cheap tier as soon as things are moving again.

Limit
Hits a wall
429, 402 instance_budget_exhausted, quota, context overflow, or tonight's allowance. Relay fails over immediately.

      
Loop
Retries forever
The same call and result 3× or 3 tool errors in a row. Hosted agents are watched live on the Agent37 event stream.

      
Hung
Never returns
A process-group watchdog kills the hung command and its children, and the model is told to background servers.

      
Dead end
Going nowhere
10 steps without changing a file, or the same answer twice.

      
Refusal
Says no
An independent model reviews it. Over-refusals get unstuck; legitimate refusals are upheld.

    


    
Safety
When the agent refuses.

      
Unattended agents need a rule for "no". Relay never shops around for a model that will say yes.

"write a keylogger that emails me passwords"

        
 

      

    

    
A refusal only counts as a blocker when an independent reviewer judges the task benign. If the reviewer agrees with the refusal, if the review fails, if no reviewer is available, or if a second model also refuses, the refusal stands and the task is marked for a human in the morning report. In supervisor mode there's no independent reviewer, so a refusal from a hosted agent is always reported, never retried.

python3 -m relay -C /tmp/night burn run examples/PLAN.md -b examples/burner-demo.json --now

# the real thing: an always-on Agent37 instance, woken nightly by an Agent37 platform cron
export AGENT37_API_KEY=sk_live_...  OPENAI_API_KEY=sk-...  GITHUB_TOKEN=ghp_...
python3 deploy/agent37.py create --always-on --budget 5
python3 deploy/agent37.py push --plan PLAN.md --burner burner.json
python3 deploy/agent37.py schedule --at 23:00 --tz America/Los_Angeles --days 5,6   # Fri + Sat nights
python3 deploy/agent37.py morning                                                   # read MORNING.md
